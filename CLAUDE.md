# Where the project context lives

The decision log, scope rules, roadmap and deferred-work register are in
**[`DECISIONS.md`](DECISIONS.md)**.

That file is the one to read first — every non-obvious choice in this
repository is recorded there with its reasoning, including the ones that
turned out to be wrong and had to be reversed.

This file exists only so that tooling which looks for `CLAUDE.md` by
convention finds the pointer rather than nothing.
